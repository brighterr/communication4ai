# 传播学与学术引文网络：文献调研

整理于 2026 年 11 月 23 日。

一篇论文引用另一篇论文，在引文图中形成一条从施引文献指向被引文献的有向边。参考文献表记录公开引用，正文可以帮助区分背景介绍、方法采用、证据支持和批评。实际阅读、知识理解和非正式交流各需要独立证据。Lievrouw 以“无形学院”为例讨论了文献计量与传播理论的关系。张小强、杜佳汇把创新扩散理论用于中国大陆新媒体研究，分析期刊论文的扩散趋势、关键节点和共现网络。 [Lievrouw，1989](https://journals.sagepub.com/doi/10.1177/009365089016005004) · [张小强、杜佳汇，2017](https://cjjc.ruc.edu.cn/CN/Y2017/V39/I7/30)

## 理论与可观察的结构

| 理论 | 可以检验的引文现象 | 所需证据 |
| --- | --- | --- |
| **两级传播与意见领袖** | 原作 A、中介 B、后续论文 C 形成两跳引文链。比较综述、教程和早期应用在跨社群路径上的出现频率与先后顺序。 | 引文边和日期筛出候选路径，正文确认沿途谈的是同一项知识。若要检验作者是否从中介获知原作，可补致谢、合作或接触记录。 [Katz，1957](https://doi.org/10.1086/266687) |
| **网络议程设置** | 从同一篇论文共同引用的文献构建共引图，检验一个社群先形成的引用组合是否在其他社群随后出现。 | 比较各社群的时序共引图，控制单篇文献热度、既有共引关系及共同趋势。共引边表示公开呈现的关联。 [Guo，2012](https://doi.org/10.1080/08838151.2012.732148) |
| **议程设置** | 检验综述、专题或学术报告重点讨论的问题，是否随后占据更多研究选题。 | 从来源文本和接收社群的论文题名、摘要分别测量议题显著性，再处理共同热点和反向影响。 [McCombs 与 Shaw，1972](https://doi.org/10.1086/267990) · [新闻关注与科研选题实证](https://doi.org/10.1371/journal.pone.0280016) |
| **创新扩散** | 追踪团队首次正式引用某项方法的时间，比较不同社群的扩散速度。 | 引文图可测首次引用，方法段、实验设置和代码可另外确认首次使用。 [Rogers，2003](https://www.simonandschuster.com/books/Diffusion-of-Innovations-5th-Edition/Everett-M-Rogers/9780743222099) |
| **框架理论** | 同一个方法跨学科流动时，被放到什么问题里解释，哪些适用条件或评价标准被保留。 | 对齐原作、中介和下游的正文片段，单独标注引用功能和内容框架。 [Entman，1993](https://doi.org/10.1111/j.1460-2466.1993.tb01304.x) |
| **把关理论** | 综述或专题从候选文献中选了哪些研究，入选后外部论文的引用去向是否随之改变。 | 用当时可得、主题相近的文献构造候选集。检验编辑或推荐系统的筛选，还需要投稿或曝光记录。 [White，1950](https://journals.sagepub.com/doi/full/10.1177/107769905002700403) · [Siler 等，2015](https://doi.org/10.1073/pnas.1418218112) |
| **结构多样性与社会强化** | 早期引用数相当时，引用者来自多个相互分离的社群，是否预示随后更广的跨社群引用。 | 按早期网络划分社群，控制文献年龄与既有热度。若要检验多次独立曝光对采用的影响，还需要作者接触数据。 [Ugander 等，2012](https://doi.org/10.1073/pnas.1116502109) · [Centola 与 Macy，2007](https://www.journals.uchicago.edu/doi/10.1086/521848) |

## 已有实证及其边界

- **学术中介。** Herfeld 与 Doehne 结合共引网络和历史材料识别科学创新的阐释者、翻译者和专业应用者。Doehne 与 Herfeld 进一步通过博弈论早期论文的致谢重建学术意见领袖所处的关系网络。郑碧丽、侯剑华结合多层引文网络与摘要相似度识别了传播者、中间人等角色。 [Herfeld 与 Doehne，2019](https://doi.org/10.1016/j.shpsa.2017.12.001) · [Doehne 与 Herfeld，2023](https://link.springer.com/article/10.1007/s11192-022-04623-z) · [郑碧丽、侯剑华，2025](https://www.sciengine.com/doi/10.3969/j.issn.1008-0821.2025.09.012)
- **共同引用与归功。** McMahan 与 McFarland 发现，正式综述出现后，注意力趋向综述本身及少数代表作，许多被综述文献的后续引用下降。Meng 等借助全文识别了概念仍在使用但原作未获正式引用的案例，部分归功转向综述、教科书或应用论文。分析时可以分别记录知识使用和引文去向。 [McMahan 与 McFarland，2021](https://doi.org/10.1177/0003122421996323) · [Meng 等，2024](https://doi.org/10.1093/pnasnexus/pgae155)
- **引文语义。** Jurgens 等用引文功能描述 NLP 研究的演变。Chen 等发现，后续论文同时引用原作和低保真度的中介时，对原主张的转述往往也更不准确。ClaimFlow 在 NLP 文献中追踪主张被支持、扩展、限缩或反驳的关系。SciTraj 预印本进一步构建了跨自然语言处理、机器学习和计算机视觉的多步主张引文路径。 [Jurgens 等，2018](https://aclanthology.org/Q18-1028/) · [Chen 等，2025](https://aclanthology.org/2025.acl-long.1534/) · [ClaimFlow，2026](https://aclanthology.org/2026.emnlp-main.67/) · [SciTraj，2026 预印本](https://arxiv.org/abs/2606.22342)
- **AI 时代的引文变化。** López-López 等已用共引聚类研究 AI Agent 文献的知识结构，样本限于商业与经济研究。Yan 与 Ni 的预印本观察到，2023 年前后，论文中疑似 AI 辅助写作的程度同引文结构之间的关联发生变化，其写作指标来自文本特征。因此，跨社群的引用组合是否变化、方向如何，仍是独立的经验问题。 [López-López 等，2026](https://www.tandfonline.com/doi/full/10.1080/08839514.2026.2684087) · [Yan 与 Ni，2026 预印本](https://arxiv.org/abs/2604.14126)

## 可配合引文图的其他理论

- **媒介生态位。** 选定面向同一任务的新旧技术，区分新作进入后旧作被替代、两者共同出现或共同增长。以具备引用机会的论文作分母，可避免只在新旧两类引文中计算份额造成的机械替代。 [Dimmick 与 Rothenbuhler，1984](https://onlinelibrary.wiley.com/doi/abs/10.1111/j.1460-2466.1984.tb02988.x) · [期刊竞争的引文网络研究，2022 预印本](https://arxiv.org/abs/2211.17164)
- **信息补贴。** 可研究软件仓库提供可直接复制的推荐引文后，引用是否由方法论文流向另一个指定记录。已有研究检查作者的实际引用与推荐格式是否匹配，进一步检验需取得历史仓库配置及软件实际使用证据。 [Gandy，1982](https://books.google.com/books?id=UsRiAAAAMAAJ) · [软件引用实证](https://pmc.ncbi.nlm.nih.gov/articles/PMC9454791/) · [GitHub 引用功能](https://github.blog/news-insights/company-news/enhanced-support-citations-github/)
- **传播调适与沉默的螺旋。** 前者可用审稿意见、作者回复和稿件版本观察受话者特有的措辞怎样进入新增引文语境。后者可研究感知到的同行共识和声誉压力如何影响署名批评，需另测研究者的私人异议与感知。现有文献分别提供了审稿互文和学术负面引用的基线。 [Giles 等，1973](https://www.cambridge.org/core/journals/language-in-society/article/abs/towards-a-theory-of-interpersonal-accommodation-through-language-some-canadian-data1/D49327958892CB1D1EBBFB9B05F3C154) · [审稿互文，2022](https://aclanthology.org/2022.cl-4.16/) · [Noelle-Neumann，1974](https://doi.org/10.1111/j.1460-2466.1974.tb00367.x) · [负面引用，2015](https://doi.org/10.1073/pnas.1502280112)
- **媒介系统依赖与知沟假说。** 前者可问学术数据库或期刊渠道中断后，原先依赖该渠道的团队是否改引替代来源。后者可问同一批新知识变得可获取后，不同资源组的了解或采用速度怎样变化。已有研究分析期刊断供与引用、开放获取与引用多样性，深入检验还需渠道使用或学习数据。 [Ball-Rokeach 与 DeFleur，1976](https://journals.sagepub.com/doi/10.1177/009365027600300101) · [Tichenor 等，1970](https://academic.oup.com/poq/article/34/2/159/1843590) · [期刊断供与引用](https://doi.org/10.1162/qss_a_00255) · [开放获取与引用多样性](https://link.springer.com/article/10.1007/s11192-023-04894-0)

## 跨社群框架与实际采用的备选案例

LoRA 原论文关注语言模型的参数高效适配，后续图像生成论文将同类方法用于个性化与风格控制。可按研究任务独立抽取下游论文，通过方法段确认实际使用，再记录它们沿用什么问题表述、引用原论文还是中介。这个案例可以对照跨社群转译、技术采用和学术归功，也适合补充图结构分析。 [LoRA 原文](https://arxiv.org/abs/2106.09685) · [Block-wise LoRA](https://arxiv.org/abs/2403.07500)

这是一轮定向文献调研。时间顺序、图形关联和文本相似度可以形成待检验的传播线索。正式分析仍需处理社群同质性、共同外部来源和数据库漏边，并说明选题样本、首发日期和时间窗口。以上提出的引文扩散、替代与共存模式均为研究问题。 [Shalizi 与 Thomas，2011](https://pmc.ncbi.nlm.nih.gov/articles/PMC3328971/) · [OpenAlex 引文数据说明](https://help.openalex.org/data/works/citations/)
